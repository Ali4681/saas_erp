ملخص التحديثات الجديدة للعميل

تاريخ الإصدار: 12 سبتمبر 2026

1) التحديثات الرئيسية

صفحة الكاشير (POS)

شاشة نقطة بيع مستقلة للمبيعات اليومية: فتح وإغلاق الوردية، البيع، المرتجعات (مع إشراف عند الحاجة)، وعرض صور المنتجات.

الصفحة الشخصية للموظف

بوابة ذاتية لكل موظف (الملف الشخصي، الحضور، الإجازات… حسب التفعيل). حساب الموظف العادي يدخل لصفحته الشخصية فقط، وليس لوحة الـ ERP الكاملة.

توليد الصور بالذكاء الاصطناعي

مسار توليد صور المنتجات بالذكاء الاصطناعي جاهز ضمن النظام. لتفعيله بشكل حي نحتاج مفتاح API لمزوّد الـ AI Agent (توليد الصور).

2) طرق تسجيل الدخول

المسار الرابط لمن؟ إلى أين؟
دخول الشركة / الموظفين /login مالك، أدمن، محاسب، موظف… المنصة الرئيسية، أو الصفحة الشخصية للموظف/الكاشير
دخول الكاشير (POS) /login/pos الكاشير / نقطة البيع شاشة الـ POS مباشرة
دخول سوبر أدمن المنصة /admin/login مدير المنصة فقط لوحة المنصة

من صفحة /login يوجد رابط مباشر لصفحة دخول الكاشير POS.

4) مطلوب من العميل

لتفعيل توليد الصور بالذكاء الاصطناعي:

نحتاج تزويدنا بـ API Key لمزوّد الذكاء الاصطناعي (AI Agent / Image Generation) حتى نفعّل توليد الصور بشكل حي داخل النظام. بدون المفتاح تظهر الواجهة، لكن التوليد الحي لا يكتمل.
